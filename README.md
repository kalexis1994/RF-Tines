# RF-Tines

![RF-Tines instrument](package/branding/banner.png)

RF-Tines is a physically modelled tine electric piano for RackForge. A hammer strikes a metal tine and a pickup turns its motion into sound. A light touch brings out the bell-like tone. A firm strike brings out the bark.

## Install

RF-Tines is included in the RackForge Standard bundle. To install it separately, download `RF-Tines.rfplugin` and choose **Install plugin** in RackForge's **Plugin Manager**. [Download RF-Tines](https://github.com/kalexis1994/RF-Tines/releases/latest)

## Choose a piano

Open **RF-Tines** in PLAY and use the program selector to move between the eight factory voices.

| Program | What to play |
| --- | --- |
| **Felt Tips 1966** | Try gentle chords for a rounder, darker attack. |
| **Portable Bark 1972** | Play the same phrase at different velocities to hear the pickup respond to harder strikes. |
| **Console Bark 1973** | Turn on **Vibrato** for the console's stereo amplitude movement. |
| **Portable Chime 1980** | Try upper-register lines for a brighter, more bell-like sound. |
| **Tine Bass 1960** | Play bass lines in its E1–B3 range. |

## Shape and save a voice

Use the panel's tone controls to fit the piano around other instruments. On programs with stereo tremolo, **Speed** sets how quickly it moves and **Intensity** sets how pronounced the movement is. **Volume** sets the output from the instrument.

In the program editor, try **Hammer Hardness** to change the attack and **Pickup Distance** to change how the tine's motion comes through. Save your own program to keep the adjustments. In **CONFIG** you can import or export saved voices as `.rftines` files.
